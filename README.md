# MallangTalk (말랑톡 - 가칭)

사용자가 직접 캐릭터와 세계관을 제작·배포하고, 메신저(톡) 인터페이스를 통해 캐릭터를 공략하는 **UGC 인터랙티브 캐릭터 톡 시뮬레이션 플랫폼**입니다.

[온더훅](https://namu.wiki/w/%EC%98%A8%EB%8D%94%ED%9B%85) 스타일의 선택지 기반 스토리 공략 시스템과 생성형 AI 기반 캐릭터·시나리오 빌더를 결합하여, 누구나 하나의 웹(PWA) 환경에서 캐릭터를 창작하고 플레이할 수 있도록 설계되었습니다.

## 주요 기능

| 영역 | 기능명 | 상세 설명 |
| :--- | :--- | :--- |
| **톡 플레이** | **선택지 기반 공략 모드 (기본)** | 제작된 시나리오와 선택지 분기 스크립트에 따라 메신저 대화를 진행하며 호감도 및 엔딩을 공략합니다. |
| **톡 플레이** | **실시간 AI 자유 대화 모드 (BYOK)** | 사용자가 개인 AI API 키(Gemini, Claude, OpenRouter 등)를 등록하고 상단 토글을 켜면, 선택지 외에 직접 원하는 대답을 입력하여 실시간 AI 응답과 호감도 판정을 받을 수 있습니다. |
| **톡 플레이** | **메신저 리얼리티 연출** | 읽음 표시(`1`) 사라짐, 상대방 입력 중(`···`) 인디케이터, 연속 말풍선 전송, 조건부 선톡 및 웹 푸시 알림을 지원합니다. |
| **제작 스튜디오** | **AI 보조 캐릭터·시나리오 생성** | 캐릭터의 성격·말투·세계관을 입력하면 AI가 초기 호감도 단계(0~100), 챕터 구조, 기본 이벤트 및 대화 분기 스크립트를 자동 생성합니다. |
| **제작 스튜디오** | **커스텀 이벤트 및 컷씬(CG) 배치** | 제작자가 원하는 호감도 구간이나 특정 분기 단계에 일러스트 컷씬(CG)을 지정하고, 직접 커스텀 이벤트와 대사를 추가·편집할 수 있습니다. |
| **세계관 확장** | **동일 제작자 캐릭터 관계도 연결** | 같은 제작자가 만든 캐릭터 간의 관계(친구, 라이벌, 연인 등)를 연결하여 대화 중 타 캐릭터의 안부·호감도 상태를 언급하거나, 특별 이벤트에서 타 캐릭터가 개입하는 연출을 지원합니다. |
| **플랫폼 환경** | **통합 반응형 웹 & PWA** | 단일 Flutter Web 코드베이스로 플레이와 제작 도구를 모두 제공하며, 모바일 홈 화면 추가(PWA Standalone) 시 네이티브 앱과 동일한 전체 화면 조작감을 제공합니다. |

## 시스템 아키텍처

클라이언트(Flutter Web/PWA)와 백엔드(Dart Server + DB)를 단일 언어(Dart) 기반으로 구성하여 데이터 모델과 검증 로직을 공유하며, Synology NAS의 Docker 컨테이너 환경에서 구동됩니다.

| 계층 | 구성 요소 | 역할 및 설명 |
| :--- | :--- | :--- |
| **Client** | **Flutter Web (PWA) + Riverpod** | 반응형 메신저 UI, 캐릭터 허브, 제작 스튜디오, 컷씬 앨범, 모바일 당겨서 새로고침 방지 적용 |
| **Backend** | **Dart Server (Shelf / Dart Frog)** | REST API & WebSocket 통신, 호감도·플래그 상태 검증, 선톡 스케줄러, AI 프롬프트 라우팅 |
| **Database** | **SQLite / PostgreSQL + 로컬 스토리지** | 다수 유저 계정, 배포된 캐릭터·시나리오·관계도 그래프, 유저별 플레이 세이브, 컷씬 이미지 저장 |
| **External** | **AI API & Web Push (FCM)** | 캐릭터 생성용 서버 AI 연동, 플레이어 BYOK 실시간 대화 중계, 백그라운드 선톡 알림 발송 |

## 프로젝트 디렉토리 구조

테마 및 디자인 토큰을 `lib/core/theme` 하위에 모듈화([taskflow_example](https://github.com/SirohaKR/taskflow_example) 구조 참고)하고, 기능 단위로 상태 관리(Riverpod)와 화면을 분리한 Feature-first 아키텍처를 따릅니다.

```text
mallangtalk/
├── docker-compose.yml                # Synology NAS 배포용 통합 컨테이너 설정
├── Dockerfile                        # Flutter Web 빌드 및 Dart 서버 실행 이미지
├── web/
│   ├── index.html                    # PWA 메타태그 및 모바일 당겨서 새로고침 방지 CSS
│   └── manifest.json                 # Standalone 웹앱 설정
├── .env.example                      # 서버 설정 예시 (AI 키, 접속 코드). .env로 복사해서 사용
├── packages/
│   └── mallangtalk_ai/               # 앱·서버가 같이 쓰는 AI 호출 코드 (Claude·ChatGPT·Gemini)
├── server/                           # NAS 백엔드 서버 (Dart, shelf)
│   ├── bin/server.dart               # 서버 켜기 (.env 읽기)
│   ├── lib/mallangtalk_server.dart   # AI 중계(/api/ai/json), 상태 확인(/api/health), 앱 화면 띄우기
│   ├── lib/accounts.dart             # 회원가입·로그인, 캐릭터 저장·받아오기 목록, 사진 API
│   ├── lib/store.dart                # SQLite DB (users·sessions·characters·images)
│   └── test/                         # 서버 테스트 (dart test)
│   # 다음 단계: 대화 진행 상황 서버 저장, 선톡 스케줄러
└── lib/                              # Flutter 클라이언트 (플레이 + 제작 통합 웹앱)
    ├── main.dart                     # 앱 진입점 및 ProviderScope 초기화
    ├── app.dart                      # MaterialApp.router 및 글로벌 테마 연결
    ├── core/
    │   ├── theme/
    │   │   ├── app_colors.dart       # 파스텔 톡 배경, 말풍선, 호감도 단계별 색상 상수
    │   │   ├── app_text_styles.dart  # 말풍선, 선택지, 헤더 타이포그래피 정의
    │   │   ├── app_spacing.dart      # 여백, 말풍선 곡률(Radius), 반응형 브레이크포인트
    │   │   └── app_theme.dart        # 라이트/다크/캐릭터 테마 ThemeData 조합
    │   ├── network/                  # API 클라이언트 및 BYOK 헤더 인터셉터
    │   └── router/                   # GoRouter 기반 화면 라우팅
    ├── shared/
    │   ├── models/                   # Character, ScenarioEvent, Choice, Relation 모델
    │   └── widgets/                  # 공통 버튼, 프로필 아바타, 컷씬 모달 뷰어
    └── features/
        ├── auth/                     # 로그인 및 개인 AI API 키(BYOK) 설정
        ├── hub/                      # 배포된 캐릭터 탐색 및 관계도 미리보기
        ├── chat/                     # 톡 플레이 화면, 선택지 패널, 실시간 AI 입력 토글
        ├── studio/                   # 캐릭터 생성(AI 보조), 이벤트·컷씬 배치, 관계도 에디터
        └── album/                    # 해금한 이벤트 컷씬(CG) 및 엔딩 수집함
```

## 시작하기 (로컬 개발 환경)

### 요구 사항
- Flutter SDK `>=3.24.0`
- Dart SDK `>=3.5.0`
- Docker & Docker Compose (서버 배포 시)

### 실행 방법

```bash
# 1. 저장소 클론 및 패키지 설치
git clone https://github.com/SirohaKR/mallangtalk.git
cd mallangtalk
flutter pub get

# 2. Flutter Web 로컬 개발 서버 실행
flutter run -d chrome --web-port=5201

# 3. 테스트 (샘플 전체 플레이, 일상 대화 순서, 진행 저장, 편집기 초안 변환, 특별 이벤트, AI 생성·자유대화 요청 형식, 하단 탭 흐름)
flutter test
(cd server && dart test)
```

### 서버로 켜 보기 (내 PC)
서버가 앱 화면도 같이 띄우고, `.env`에 넣은 키로 AI를 대신 불러 줘요. 브라우저에 키를 넣지 않아도 됩니다.

```bash
cp .env.example .env            # 쓸 AI 회사 키와 ACCESS_CODE(선택)를 채움
flutter build web --no-web-resources-cdn
cd server && dart pub get && dart run bin/server.dart
# → http://localhost:5200 접속. 설정 탭에 '말랑톡 서버에서 열었어요'가 보이면 성공
```

서버에서 열면 먼저 **아이디·비밀번호 로그인** 화면이 나와요(아래 `회원가입`으로 계정 만들기). 로그인하면 내가 만든 캐릭터가 서버 DB(`data/mallangtalk.db`, SQLite)에 저장되고, 올린 사진도 DB로 옮겨져서 캐릭터 파일에는 `/api/images/…` 주소만 남아요. `말랑이 찾기`에는 다른 유저들이 만든 캐릭터가 보여요(아래로 당기면 새로고침). 친구로 추가하면 서버에 친구 수가 올라가서 인기순에 쓰여요.

AI는 지금 **각자 설정에 넣은 내 API 키**로만 불러요(서버 `.env` 키는 `USE_SERVER_AI_KEYS=false`로 잠겨 있음). 처음엔 무료 한도가 있는 Gemini가 기본이고, 설정의 `Gemini 키 받으러 가기`로 aistudio.google.com에서 키를 받을 수 있어요. 서버 키를 다시 켜려면 `.env`에서 `USE_SERVER_AI_KEYS=true`로 바꾸고, 그때는 ACCESS_CODE를 정해 앱 설정 탭의 `서버 접속 코드`에 같은 값을 넣어 주세요. claude.ai 플레이 링크는 바깥 주소 호출이 막혀 있어서 서버를 쓸 수 없고, 거기서는 계속 내 키(BYOK)로만 AI를 부를 수 있어요(Claude 키만 동작).

### 앱 화면 구성 (하단 탭)
| 탭 | 하는 일 |
| :--- | :--- |
| **말랑이 찾기** (첫 화면) | 검색창(이름·태그·만든 사람), 태그 칩, 오늘의 추천(친구 수 + 최근에 올라온 덤), 새로 올라온 말랑이(최신·인기 정렬). 카드마다 만든 사람이 보이고 누르면 제작자 프로필. 상세 화면 아래 `친구 추가하고 대화하기` |
| **채팅** | 대화 중인 캐릭터 목록. 마지막 말풍선, '입력 중...', 안 읽은 톡 숫자 표시 |
| **내 말랑이** | **친구**: 내 프로필, 즐겨찾기, 친구 목록. 프로필에서 캐릭터 설정 보기, 1:1 채팅, 앨범, 대화 속도, 처음부터 다시, 고치기, 캐릭터 파일로 내보내기, 삭제 / **내가 만든**: 만든 캐릭터와 `수정` 버튼, 관계도. 오른쪽 위 `만들기`로 앱 안 편집기(직접 입력 + AI로 만들기) |
| **설정** | 계정 카드 + **계정 · 프로필**(기본 별명, 한줄 소개, 사진, 기본 페르소나, 로그아웃) / **AI 연결**(AI 회사·키·모델, 서버 접속 코드는 고급 안) |

- **채팅 시작과 별명**: 친구로 추가한 캐릭터와 처음 대화할 때 '이 대화에서 쓸 내 별명'을 묻고(설정의 기본 별명이 미리 들어감) 정한 뒤에 톡이 오기 시작합니다. 대화방 메뉴에서 언제든 바꿀 수 있습니다. 대본과 설정의 `{{user}}`(또는 `{이름}`)는 별명으로, `{{char}}`는 캐릭터 이름으로 바뀌고, 뒤에 붙은 조사(아/야, 이/가, 은/는, 을/를, 과/와, 이랑/랑)는 받침에 맞게 바뀝니다.
- **대화 속도**: 캐릭터마다 따로 정합니다(대화방 메뉴 또는 프로필의 `대화 속도`: 리얼하게 / 조금 빠르게 / 빠르게).
- **앨범**: 캐릭터가 보낸 사진 말풍선과 컷씬이 구분 없이 앨범에 모입니다. 호감도 단계별로 묶여 있고, 못 받은 사진은 자물쇠 칸으로 남아요. 사진을 누르면 흐린 배경 위에 크게 보이고 옆으로 넘길 수 있어요.
- **톡방 꾸미기**: 캐릭터 대표색으로 배경(연하게)·내 말풍선·선택지 테두리·윗줄을 꾸밉니다. 글자색은 말풍선 밝기에 맞춰 흰색·검은색 자동.
- **호감도 말랑이**: 대화 중 캐릭터 프로필에 말랑이가 대표색으로 차오르고 지금 단계 이름만 보여요 (숫자·다음 단계 이름은 숨김).
- **자유대화 AI 고르기**: 대화방 메뉴(또는 자유대화 방 이름 아래 표시)에서 AI 회사·모델을 바로 바꾸고, 키가 없으면 그 자리에서 붙여 넣어 연결해요.

### 캐릭터 만들기
- **말랑이 찾기 성별 필터**: 검색창·장르 칩 아래 성별 칩(전체·남성·여성·미정)으로 목록을 걸러요. 성별을 안 고른 말랑이는 '미정'에 함께 보입니다.
- **캐릭터 설정 항목** (캐릭터 아카이브 [loreshelf](https://github.com/SirohaKR/loreshelf) 참고): 플레이어에게는 갤러리 상세·프로필에 **캐릭터 정보**(나이·직업 등 항목, 자물쇠로 숨김 가능) / **캐릭터 설정** / **세계관 설정** / **나는 이 이야기에서** / **주변 인물**만 보입니다. 호감도 단계, 이야기 분량, 타자 스타일, 성격 막대, 대사 예시, 비밀 설정은 제작자와 AI만 씁니다(비밀은 AI 자유대화에 '서서히 드러낼 설정'으로 넘어감).
- **앱 안 편집기** (엑셀 대신): `내 말랑이 > 만들기`에서 한 화면에 한 단계씩 8단계로 만듭니다. **기본**(사진·이름·상태 메시지·한줄 소개·태그) → **대표색**(색 고르기·직접 입력, 톡방 배경 연하게/흰색, 내 말풍선 대표색/기본 분홍, 미리보기) → **프로필**(성별 남성/여성/미정, 프로필 항목과 자물쇠) → **성격·말투**(대표 대사·대사 예시·타자 스타일) → **이야기**(캐릭터 설정·세계관·나는, 넓은 칸과 글자 수) → **인물·비밀** → **호감도·대본**(맨 위 `AI로 생성하기`, 호감도 단계, 대화 목록, 대화를 펼쳐 `대사 편집`) → **마무리**(사진함 확인·작가 코멘트·말랑이 찾기에 올리기). 위의 8칸 막대를 누르면 바로 그 단계로 갑니다. 저장할 때 빠진 곳을 알려 주고, 좋은 선택만으로 끝까지 못 가면 호감도를 자동으로 맞출지 묻습니다. 만든 캐릭터는 프로필의 `고치기`로 다시 열고, 메뉴에서 캐릭터 파일(.json) 불러오기·내보내기를 할 수 있습니다.
- **AI로 생성하기**: 7단계 맨 위 버튼. 1~6단계 설정과 호감도 단계를 토대로, 단계별 이벤트·일상 대화 수와 특별 이벤트 수를 고르면 설정에서 고른 AI가 목차와 모든 대사를 써서 편집기에 채웁니다. 비어 있는 한줄 소개·태그·세계관·프로필 항목도 채우고, 제작자가 적은 칸은 그대로 둡니다. 대화 옆 ✨로 그 대화만 다시 쓸 수 있고, 3~6단계의 `빈 칸 AI로 채우기`는 그 단계의 빈 칸(프로필 항목 / 대표 대사·대사 예시·성격 / 세계관·나는 / 주변 인물·비밀)만 채웁니다. 성별은 AI 설정에 들어가고, 미정이면 AI가 성별을 드러내지 않게 씁니다.
- **호감도 단계와 일상 대화**: 이벤트·일상 대화마다 호감도 단계 이름을 붙입니다. 이벤트는 그 단계가 되면 열리고, 일상 대화(`event_type: daily`)는 그 단계에 머무는 동안에만 호감도 이벤트 사이사이에 하나씩 나옵니다. 다음 이벤트 조건이 안 맞으면 남은 일상 대화로 호감도를 더 쌓을 기회를 줍니다. 일상 대화는 공략 완료 조건에 들어가지 않습니다.
- **엔딩과 놓친 사진**: 엔딩(공략 완료)은 사진을 다 모으지 못해도 호감도 이벤트를 모두 끝내면 나옵니다. 다른 갈래로 가서 못 받은 사진은 공략 뒤 `안 본 갈래 다시 보기`(대화를 처음부터 다시 보되 호감도·진행은 그대로)로 모으거나, 다음 회차에 예전에 안 고른 선택지가 ✨로 반짝여요(고른 선택지는 `chosen_<id>`에 회차를 넘어 저장, 기기 연동).
- **일상 대화 순서와 이어지는 대화**: 같은 단계의 일상 대화는 무작위 순서로 나옵니다. 편집기에서 `이어지는 대화`로 앞 대화를 고르면(`follows`) 그 대화가 끝난 바로 뒤에 붙어서 나와요.
- **공략 후 이야기** (`event_type: after_ending`): 엔딩을 본 뒤 순서대로 오는 대화. 사진도 넣을 수 있고, 공략 조건에는 안 들어갑니다.
- **사진 보낼 때 (자유대화)**: 편집기 이벤트 사진함에서 사진을 누르면 감정·상황·키워드(와 사진 설명)를 적을 수 있어요(`events[].photo_triggers`, 사진 번호별). 자유대화 방에서는 이걸 적어 둔 사진만 AI에게 보여 주고, 대화가 조건에 맞을 때만 AI가 골라 보내요. 받은 사진은 앨범('자유대화에서 받은 사진' 묶음)에 들어갑니다.
- **시간 표시와 특별 이벤트**: 이벤트 앞의 안내는 실제 시계와 어긋나지 않도록 `다음 날`, `그날 밤`, `며칠 뒤`처럼 **장면 전환 문구**로만 씁니다. 시간대가 중요한 대화는 **특별 이벤트**(`event_type: special`, `real_time: {from_hour, to_hour, date}`)로 만들어, 플레이어가 실제로 그 시각(예: 밤 10시~새벽 2시, 12월 25일)에 대화방에 있을 때만 한 번 옵니다. 첫 이벤트를 끝낸 뒤부터 오고, 다시 하기를 해도 또 오지 않으며, 공략 조건에는 들어가지 않습니다. 공략을 끝낸 뒤에도 그 시간에 들어오면 옵니다.
- **타자 속도**: 캐릭터마다 타자 스타일(번개같이 0.6 ~ 한참 고민 1.7)이 있고, 말풍선마다 읽고 멈칫 → 입력 중(글자당 약 0.15초) → 망설이는 말은 치다 멈췄다 다시 치는 연출을 합니다. 캐릭터별 대화 속도가 여기에 곱해집니다.

### 사용량·플레이 시간 재 보기
`flutter test tool/measure_usage_test.dart`를 돌리면 50개 대화짜리 캐릭터를 AI로 만들 때의 모델별 토큰·금액과 예상 플레이 시간을 `build/usage_report.md`로 뽑아 줍니다. 실제 API는 부르지 않고, 예시 캐릭터 대사로 응답 길이를 어림합니다.

### 자유대화(BYOK) 써 보기
`설정 > AI 연결`에서 AI 회사(Claude·ChatGPT·Gemini)를 고르고 그 회사 API 키를 넣고 모델을 고른 뒤, 자유대화 방에서 직접 입력하면 캐릭터가 AI로 답장합니다. 캐릭터와 처음 대화할 때 **스토리**/**자유대화** 중 골라 시작하고, 두 방은 따로 이어져요(대화방 메뉴의 `자유대화 방 열기`·`스토리 대화방으로`로 오가고, 채팅 목록에 방마다 이름표가 붙음). 자유대화 방은 정해진 이야기·호감도 없이 캐릭터 설정과 내 설정(페르소나)대로 AI가 답합니다. 엔터로 보낸 뒤에도 입력창에 커서가 남아 짧게 여러 번 이어서 보낼 수 있습니다. 키는 브라우저 저장소에만 남고, 키는 회사마다 따로 저장돼요. 말랑톡 서버에서 열었고 서버 `.env`에 그 회사 키가 있으면 내 키 없이 서버가 대신 부릅니다(서버는 키·대화 내용을 기록하지 않음). 그 밖에는 브라우저에서 각 회사 API를 바로 호출합니다(`packages/mallangtalk_ai`).

### 서비스 말랑이 (운세·행운의 편지처럼 먼저 톡 보내기)
만들기 첫 단계에서 종류를 **서비스 말랑이**로 고르면 단계가 기본 정보 → 프로필 → 보내기 → 마무리로 줄어요. 이야기·호감도 단계·엔딩 없이 호감도는 처음부터 100이고, 정해진 요일·시각마다 캐릭터가 먼저 톡을 보내요(앱을 안 켠 동안의 톡은 대화방을 열면 그 시각으로 쌓임, `svc_<id>`에 마지막 보낸 때 저장). 문구는 세 가지로 만들어요.
- **문구 목록**: 한 줄에 하나씩 적어 두면 랜덤으로 (한 바퀴 돌 때까지 같은 문구 안 나오게 할 수 있음)
- **데이터 표**: 엑셀·시트에서 복사한 표(첫 줄이 칸 이름)를 붙여 넣고, 틀에 `{칸 이름}`을 넣으면 한 줄씩 채워 보냄
- **AI**: 적어 둔 지시대로 AI가 그때그때 씀 (AI 연결 필요)

어느 모드든 `{이름}`·`{날짜}`·`{요일}`·`{숫자}`(1~45)를 넣을 수 있고, 켜 두면 대화방에 **한 번 더 뽑기** 버튼이 생겨요. 말을 걸면 캐릭터 설정대로 AI가 답합니다. 데이터는 `character.kind = "service"`, `character.service`(days·times·mode·lines·columns·rows·template·ai_prompt·no_repeat·reroll).

### 샘플 시나리오
앱에는 샘플 캐릭터가 들어 있지 않아요(2026-10 화면 개편 때 뺌). 테스트용으로 `test/fixtures/sample_character.json`에 **윤도하**(1년 된 남사친: 호감도 이벤트 6개, 단계별 일상 대화 6개, 특별 이벤트 2개, 엔딩), `test/fixtures/example_seo_ijun.json`과 `template_scenario.dart`에 **서이준**이 있습니다. 이 파일 형식이 그대로 캐릭터 파일(.json) 내보내기/받아오기와 서버 데이터 형식의 기준입니다.

## Synology NAS (Docker) 배포 방법

GitHub에 푸시된 소스를 Synology NAS에서 클론한 뒤 Docker Compose로 빌드 및 실행합니다.

```bash
# 1. NAS SSH 접속 후 프로젝트 폴더 이동
cd /volume1/docker/mallangtalk

# 2. 환경 변수 파일(.env) 생성 후 AI 키·ACCESS_CODE 채우기
cp .env.example .env

# 3. Docker 컨테이너 빌드 및 백그라운드 실행
docker compose up -d --build
```

이미지 안에서 Flutter(3.47.7)로 앱 화면을 빌드하고 서버를 실행 파일 하나로 만들어서, 처음 빌드는 10분 넘게 걸릴 수 있어요. 집 밖에서도 열리게 할 거면 `.env`의 `ACCESS_CODE`를 꼭 정해 주세요(안 정하면 주소를 아는 누구나 내 키로 AI를 부를 수 있어요).

배포 후 Synology DSM의 **역방향 프록시(Reverse Proxy)** 설정에서 외부 HTTPS 도메인을 컨테이너 포트(기본 `5200`, `.env`의 PORT로 변경)로 연결하면 모바일 및 PC 브라우저에서 즉시 접속할 수 있습니다.
